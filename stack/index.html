How it works

You stack the pieces yourself. Drex Max gets the same piece as a list of every place it can drop, with what each drop would do (rows cleared, new holes, how bumpy the surface gets, what the next piece could do after), and picks one. Its board places each piece when you place yours. A garbage row rises every 12 pieces. Most rows cleared in 150 pieces wins.

Drex Max's board replays one game recorded on 19 Oct 2026 with real Drex API answers, one request at a time (seed 33, 150 pieces). Your board gets the same pieces in the same order and the same garbage rows. Add ?clip to the address for a clean frame to screen-record.

One question, 34 options, a probability for each. Ranking and picking from a list is what Drex does for agents. New accounts get $25 of credit.
