Setup. Model drex-max on the hosted endpoint console.nace.ai/v1/systemone, called from a laptop in Almaty, one request at a time. Answer times are full round trips, network included.

What Drex sees. Only text: the situation and one typed question listing the options, with plain facts about each (for example "clears 1 row, no new holes"). No scores, no hints about which option is right, no images.

Replays. Each game is deterministic for a seed, so a recording replays exactly: the page re-runs the game with Drex's recorded answers and recomputes the result. Recorders are in the repo.

You vs Drex. Your game uses the same seed: same messages, obstacles, pieces or apples. Your best is kept in this browser only; nothing is sent anywhere.
